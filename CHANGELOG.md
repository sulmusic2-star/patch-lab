# Changelog

## 0.2.0 — 2026-08-21

- Added Reward Radar for Google Open Source Security Patch Rewards, including
  official-scope receipts, repository matching, policy checks, bounded static
  profiling and fail-closed candidate dossiers.
- Added deterministic HubSpot repository evidence reports in JSON, Markdown and
  HTML.
- Added redaction, symlink, size, binary-file and absolute-path safeguards.
- Added a dependency-free test suite covering 40 behaviors on Node.js 20 and 22.

This release does not automate vulnerability disclosure, pull requests, reward
claims or target-code execution.
